# Tabletop 桌面小游戏

在 Minecraft 里玩七连翻和暗流涌动，包含座位管理、说书人操作、规则资料和桌间手机。

Minecraft **1.21.1 / Fabric / Java 21**。源码版本 `0.5.10+mc1.21.1`，Mod ID：`tabletop`。

2026-10-17 / 0.5.10：同步最新七连翻与血染钟楼源码。七连翻包含八座位发牌、桌面与头顶公开牌同步及牌面显示；钟楼包含同时投票、选择结果进入魔典、夜晚私聊提示、身份牌座位展示及处决/夜刃效果。

输入 `/tabletop` 或 `/tt` 查看帮助。道具在创造模式的桌游物品栏中；右键使用道具，背包里有手机时可按 **H** 打开。联机时客户端和服务器安装相同版本。

模型和纹理由项目脚本生成，不包含桌游扫描图或玩家存档。玩法和名称的引用不代表获得原桌游的官方授权。
